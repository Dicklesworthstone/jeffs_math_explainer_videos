Can a loop count what it cannot see?

Track the boundary in the input plane and its image in the output plane for f(z) = (z − 0.45) / (z − 1.35). The input loop runs counterclockwise. The image’s signed turns around zero count enclosed zeros minus poles.

Input plane

White dot: zero. Dark ring: pole. Circle: the input path. Move the cyan point to see its image. Hue shows output angle.

Output plane

Gold curve: the image of the loop. Cyan point: the image of the moving input point. The cross marks zero. Axes span −4 to 4.

Hue repeats after one turn; brightness bands encode output magnitude. The exact zero and pole have no assigned phase. The output scale expands near the pole, so size cannot be compared between radii without reading the scale. Radius 0.45 or 1.35 puts a zero or pole on the contour: the mapped path is withheld and winding is undefined. This numerical visual is a prototype, not a proof.
