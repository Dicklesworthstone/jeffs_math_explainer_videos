## Backwards TTS: four different ideas, with different evidence obligations

**A. Conditional likelihood — feasible research, not an emotion posterior.** Encode observed audio `a` with the **scoring model's own codec**, giving `z`. Hold target text `x`, speaker reference `r`, boundaries and codec fixed. For a model with a valid conditioning input `c`, teacher-force the observed tokens and inspect

`L(c) = sum[t,g] log p_theta(z[t,g] | x, r, c, previous time tokens, earlier groups at t)`.

Score only the target audio, mask prompt/padding correctly, account for the model's actual factorization and terminal token, and use full unsampled log probabilities rather than top-k-renormalized generation scores. Separate semantic and residual-code contributions. Per-token normalizations or group weights are useful diagnostics but alter the probability interpretation. For one fixed audio, candidate lengths are equal; comparisons across audio lengths require explicit treatment, not raw sums.

`softmax(L(c))` is **not a calibrated probability of emotion**. At best it normalizes fit over a finite chosen set under strong modeling/prior assumptions; natural-language descriptions are not disjoint exhaustive emotions. Text, reference identity/content, codec fit, speaking rate and recording artifacts can dominate. Current FTTS Base has reference conditioning but no demonstrated actor-instruction channel; changing neutral/animated references also changes reference content and acoustic details. Call its first result **relative exemplar compatibility**, not emotion detection. A flow-matching training/reconstruction loss is not interchangeable with a normalized autoregressive likelihood.

**Cheapest discriminator:** a bounded later sidecar using a small fixed set of human-rated Michael recordings/reference packs and held-out texts; first verify scoring alignment against a known teacher-forced cell. Existing T/`crates/ftts-conformance/tests/pq_distributional_tf.rs:1` supplies relevant seams, not this ready feature. Compare against pause/F0/rate alone and against a constant/prior predictor. Stop within one engineer-day if arbitrary target scoring needs substantial plumbing. Do not port a model to obtain a speculative score.

**B. Latent probes — representation evidence, not inversion.** V17 freezes hidden states and fits a small perceived-delivery probe. Split by complete source take, text, reference and generator; include leave-speaker-out checks for general claims and a separately held-out Michael set for channel-specific claims. Contrast with acoustic and text-only baselines. Strong prediction does not show a causal emotion axis; it may expose phonetics or a generator watermark. No probe training is done now.

**C. Analysis-by-synthesis / latent search — a larger hypothesis.** V18 searches a supported prompt/style setting to match features of observed speech, then tests whether that inferred setting transfers to different text while preserving Michael. Non-uniqueness matters: many combinations of pitch, rate, timbre and emotion can match the same recording. Require held-out transfer and human listening, penalize identity/content loss separately, and cap iterations. EmoSteer's activation intervention is related evidence that control directions can exist in particular flow-model layers; it is not proof of a Qwen emotion inverse or portable vector. [Primary paper](https://arxiv.org/html/2508.03543v1).

**D. Audio-language interpretation — ready inference, unqualified judgment.** V14 directly conditions a language model on audio. It can describe perceived delivery without a teacher-forced generative audio likelihood. Conversely a TTS model generating convincing emotion has not thereby acquired an exposed, calibrated classifier. Evaluate these alternatives on the same blinded held-out material; do not select whichever gives the most agreeable criticism.

**License boundary for all four.** Apply the matrix's [pinned Drama 3 §IV(b) restriction](https://huggingface.co/fishaudio/drama-3/blob/e0a9218aa48888270f06ef1ed9ea67622c0e17d2/LICENSE) to these experiments. Independent permissive detectors come first. Neither Fish nor Index analysis/generation outputs are assumed-permitted commercial FTTS supervision; obtain explicit disposition for any broader reuse.

## Clone first; adapt only after a measured ceiling

Approved synthetic Michael audio can be a cloning reference without any model training. That is the first bridge to test. Training another model on approved Michael examples is a different experiment: curate diverse clean source passages, preserve every teacher/voice/script hash and exact transcript, and split by text/source take before augmentation. A proposed first adaptation budget is only 10–20 curated minutes and one capped run, not a claim that this amount suffices. Never recursively add the student's own attractive outputs to its training bank and call that evidence of preserving Michael.

The [official Qwen fine-tuning recipe](https://github.com/QwenLM/Qwen3-TTS/blob/022e286b98fbec7e1e916cb940cdf532cd9f488e/finetuning/README.md) gives a concrete later implementation starting point. Hold out mathematical numbers/names, unfamiliar text and a longer passage; compare against frozen inference-only cloning, not only the training teacher. Fine-tuning a voice does not automatically add a usable emotion-instruction interface, especially to a path whose instruction handling is absent. A potentially native-compatible adapted checkpoint still needs format conversion, architecture/prompt/codec compatibility and regression/listening qualification before FTTS consumes it. Parler adaptation or a different backbone has its own training/control/data requirements; no `.spk` conversion solves that. Restricted teacher outputs stay excluded as specified in the matrix and task gates.

2. **Separate three axes.** Speaker identity, intended English accent and cadence/explanatory expression each get their own human label and timestamps. Lexical correctness is a hard separate requirement. A great pitch contour cannot compensate for changing a mathematical claim.

5. **Control text and person leakage.** Cross neutral versus emotionally suggestive texts with restrained versus expressive delivery. Use the same text across conditions. Hold out entire text passages, takes and enrollment/reference selections before tuning. Do not put adjacent windows from one take into both training and test. Speaker negatives should include similar-accent speakers; acceptable Michael expressiveness is a positive, not automatically drift. Keep model names, prompt labels and provenance hidden from judges.
6. **Audit channel and semantic shortcuts.** On analysis copies test gain/resampling/codec nuisance sensitivity, transcript-only/no-audio/wrong-audio controls for audio-language models, and text-only predictors for learned labels. Acoustic-only classifiers still hear the phonetic text; “no transcript input” does not eliminate text leakage. Group results by passage/source generator/length and report abstention and tracker disagreement.
7. **Blind, then inspect.** N7's repeated anchor, matched playback gain, whole-passage listening and all-seed early/middle/late checks apply. Prefer three listeners including one familiar with the intended accent. Predeclare the 2/3 preference-per-passage rule, severe owner-rejected switch rubric, lexical veto and provisional 2× A1 synthesis-seconds/accepted-minute budget. Record listener and repair time separately. Owner-only results stay preference results.
8. **Calibrate detectors after labels, not vice versa.** Any V04 thresholds fit only development groups. Lock them before the held-out comparison; report confusion counts, uncertainty and false-flag burden. Fewer than 20 examples per class cannot satisfy the proposed local qualification sample floor. No single objective score or weighted average authorizes voice acceptance; human rejection overrides a green detector panel. One model agreeing with another is not independent ground truth.
9. **Make an honest decision.** Qualified improvement, acceptable unchanged incumbent, inconclusive, and absolute quality failure are separate outcomes. Reuse the latest versioned N7/N8 decision in N3/N4/N11. If a detector adds no utility, retire it; if a model loses Michael, reject it despite expressive demos. The controlled evidence and small accepted example, not a closed task, justify productization.
