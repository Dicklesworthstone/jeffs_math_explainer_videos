## Description

```text
Animated explanations of the mathematics inside real systems: how to count fish you have never seen, the arithmetic that lets a broadcast survive lost packets, and the algorithm that lets programs take turns. Each video starts from a concrete puzzle and builds the formulas from it, so that a curious fourteen-year-old can follow along and a mathematician finds nothing wrong.

Every video is a Rust program built on franken_manim and narrated by a synthetic voice (FrankenTTS). Every number on screen is computed by the code that draws it and checked against an independent calculation. The source of every video, with its notes and references, is on GitHub:
https://github.com/Dicklesworthstone/jeffs_math_explainer_videos
```
