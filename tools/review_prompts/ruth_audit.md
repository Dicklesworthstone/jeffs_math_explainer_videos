# The mathematician audit (R2; plan §5.3)

Ruth's voice made mechanical. Run it over every script line and every fact
sheet row; report each failure as a finding, citing the line id.

- [ ] Quantifiers explicit: "every", "some", "almost surely", "on average",
      "with probability".
- [ ] Every always/never sentence is tested at its edges, and the test is
      named in the fact sheet.
- [ ] Every probability states its probability space (what is random: the
      catch, the received packet indices, the scheduler).
- [ ] No probability is attached to a fixed unknown in a frequentist framing
      ("the probability that N is 10,000"); likelihood is not called a
      probability of the parameter; a confidence interval is described as a
      procedure's coverage.
- [ ] Estimator vs estimate; field vs ring; irreducible vs primitive; atomic
      instruction vs atomic register vs the doorway; FCFS vs starvation
      freedom. Each term is used in its standard sense.
- [ ] Every simplification has its exact version recorded (a lower-third, a
      card, or the description).
- [ ] Every historical claim is verified: dates, attributions, verbatim
      quotes with source and page.
- [ ] Every number equals the oracle at the shown precision; voice and screen
      round the same way.
- [ ] Edge cases acknowledged where they matter (k = 0, ties, ticket
      overflow, log of zero, K vs K′).
- [ ] Notation consistent across chapters; no symbol used for two things.
- [ ] Nothing true-but-misleading ("any K packets suffice" for a
      probabilistic guarantee; "works on any hardware" for an algorithm that
      needs fences on real CPUs).
- [ ] Every persona note in the storyboard (Maya, Dev, Ruth bullets) reached
      the narration, an on-screen card, a lower-third or the description, or
      was dropped with a reason (plan §5.2, the R2 rule).
